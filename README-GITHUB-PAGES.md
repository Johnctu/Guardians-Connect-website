# Guardians Connect — GitHub Pages flat-root fix

This version keeps all service detail pages in the repository root.
Upload all files in this extracted folder directly to the root of the GitHub repository.
Replace existing files with the same names.

Examples:
- household-tasks.html
- personal-care-support.html
- support-coordination.html

This avoids 404 errors caused by the browser upload flattening/removing the services folder.
