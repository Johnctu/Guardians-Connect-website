# Guardians Connect — GitHub Pages ready

This package is configured for the repository:

- GitHub repository: `Johnctu/Guardians-Connect-website`
- Live Pages URL: `https://johnctu.github.io/Guardians-Connect-website/`

## Upload

Upload **all files and folders in this ZIP directly to the root of the `main` branch**.
Do not upload the ZIP itself and do not place the website inside a `dist` folder.

The repository root should contain `index.html`, `styles.css`, the `images` folder, the `services` folder, and the other files in this package.

GitHub Pages settings:
- Source: Deploy from a branch
- Branch: main
- Folder: /(root)

This version includes the 21 service images and changes root-relative links so they work under the GitHub Pages project path `/Guardians-Connect-website/`.

When you later connect `guardiansconnect.com.au` as a custom domain, the URLs should be changed again for the custom-domain root.
